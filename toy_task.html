Toy 例子里 tokens_per_frame = 4，所以 frame_id = token_id // 4。 下方 attention map 的上边是 key/value tokens，左边是 query tokens；赤、橙、黄、绿、青分别表示 frame 0 到 frame 4。

Toy 例子中：post_patch_height * post_patch_width = 4， hidden_states.shape[1] = 5 * 4 = 20， 所以 FramewiseCausalMask(shape=(20, 20), tokens_per_frame=4)。
7

FramewiseCausalMask 通过 frame id 判断可见性

src/maxdiffusion/kernels/splash_attention/splash_attention_mask.py
def framewise_causal_mask_function(q_ids, kv_ids):
  q_frame = q_ids // self.tokens_per_frame
  kv_frame = kv_ids // self.tokens_per_frame
  return q_frame >= kv_frame

4. 当前 MaxDiffusion 配置中的实际数值

当前配置输出 81 帧视频，但 transformer self-attention 工作在 VAE 压缩后的 latent frames 上。 对 height=480、width=832、Wan patch size (1, 2, 2)： 

# video output frames
num_frames = 81

# latent frames after VAE temporal compression
latent_frames = (81 - 1) // 4 + 1 = 21

# latent spatial size
latent_height = 480 // 8 = 60
latent_width = 832 // 8 = 104

# after Wan patch_embedding, patch_size=(1, 2, 2)
post_patch_num_frames = 21
post_patch_height = 60 // 2 = 30
post_patch_width = 104 // 2 = 52

tokens_per_frame = 30 * 52 = 1560
sequence_length = 21 * 1560 = 32760
FramewiseCausalMask.shape = (32760, 32760)
